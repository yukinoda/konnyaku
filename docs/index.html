Konnyaku
日本語 GitHub

Select any text. Press ⌃⌥T. Read it in English.

Konnyaku is a free menu-bar translator for Mac. It runs PLaMo 3 Translate on your Mac, so what you translate never leaves it.

Download for Mac Apple silicon, macOS 14 or later

What it does

Stays on your Mac
The model runs locally through llama.cpp. No account and no API key. The network is used only to download the model.
Works in any app
Select text and press the shortcut (⌃⌥T unless you change it in Konnyaku's Settings), or use Services from the right-click menu.
Japanese and English
Japanese ⇄ English by default. Chinese, Korean, French, German and Spanish are available as targets.
Popup or editor
A small popup appears next to the pointer. Press ⌘E for an editor that translates as you type.
Two model sizes
Fast 0.8B (573 MB, the default) or higher-quality 2B (1.8 GB). Only the one you pick is downloaded, and it is checked against a pinned SHA-256.
Light on memory
About 0.8 GB of RAM with the default model, freed after 5 minutes idle. Once the model is loaded, a sentence translates in well under a second.

Install

Konnyaku is not notarized by Apple (that needs a paid developer account), so macOS asks you to approve the first launch.

  1. Download Konnyaku-<version>-arm64.dmg from GitHub Releases, open it, and drag Konnyaku to Applications.
  2. Open Konnyaku and dismiss the warning.
  3. In System Settings, open Privacy & Security, scroll down, and click Open Anyway next to Konnyaku.
  4. When Konnyaku asks for Accessibility, allow it. That is how it reads the text you select.

Prefer the terminal? Remove the quarantine flag instead:

xattr -dr com.apple.quarantine /Applications/Konnyaku.app

Open source

Konnyaku is built in Swift, and its code is MIT-licensed. Read the code, report a problem, or build it yourself on GitHub. There is also a command-line version for scripts.

Built with PLaMo. Translation is done by PLaMo 3 Translate from Preferred Networks, run by llama.cpp. The model weights are licensed separately under the PLaMo Community License; it has conditions for commercial use, including use at work. Read the license notes before using Konnyaku for work.
