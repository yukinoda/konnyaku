# Code of conduct

Konnyaku follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be respectful, assume good faith, and keep discussion about the
work. Harassment and personal attacks are not tolerated in issues, pull
requests, or any other project space.

## Reporting

To report behaviour that breaks this code, use **Report content** in the
`...` menu of the comment, issue or pull request. The maintainer reviews
reports and enforces the code using the Covenant's
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
For anything that needs GitHub staff, such as spam or threats, use
[GitHub's abuse report](https://support.github.com/contact/report-abuse).
